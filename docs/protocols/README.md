# Protokoli

Protokol je kratko, obavezno uputstvo za situaciju koja se ponavlja i koja može da stvori glavobolju. Svaki protokol počinje odeljkom „Kada se primenjuje", pa kada prepoznate svoju situaciju u tom odeljku, pratite korake redom.

| Protokol | Kada se primenjuje |
|---|---|
| [Podešavanje radne stanice](podesavanje-radne-stanice.md) | Jednom, pre prvog rada na projektu. |
| [Migracije: lokalni rad](migracije-lokalni-rad.md) | Svaki put kada menjate model podataka svog modula. |
| [Testna baza podataka](testna-baza.md) | Kada integracioni testovi padaju iz razloga koji ne liči na vaš kod. |

Ako protokol ne pokriva vašu situaciju ili vas neki korak dovede u problem, javite se asistentu.
